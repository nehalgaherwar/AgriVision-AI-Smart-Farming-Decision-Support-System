# 🌾 AgriVision AI - Smart Farming Assistant


A web-based farming assistant that helps farmers:
- Get crop recommendations based on soil type
- Check pest information
- Calculate expected profit

---

🚀 Project Idea

Ek web-based smart farming tool jo farmer ko bataye:

Soil type ke hisaab se kaunsi crop best hai

Weather ke basis par irrigation advice

Fertilizer recommendation

Expected profit estimation

Pest alert system

Ye simple crop recommendation se advanced hoga — ek mini “Farmer Assistant”.

---

## 🚀 Tech Stack
- HTML
- CSS
- JavaScript
- Python (Flask)

----

## ▶️ How to Run

1. Install requirements
   pip install -r requirements.txt

2. Run the app
   python app.py

3. Open browser:
   http://127.0.0.1:5000/

----


🔥 Run Karne Ka Tarika
pip install flask
